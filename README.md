# 📝 To-Do List App with SwiftData  

A simple and efficient **To-Do List app** built with **SwiftData** to store tasks persistently. This project applies concepts from **Hacking with iOS: SwiftUI Edition**, integrating accessibility and modern iOS features.  



## 🚀 Features  

✅ **SwiftData Integration** – Persistent storage for tasks.  
✅ **Categories & Icons** – Organize tasks by category with custom icons.  
✅ **Task Management** – Add, complete, and track tasks with timestamps.  
✅ **VoiceOver Support** – Ensures accessibility for visually impaired users.  
✅ **User Notifications** – Sends reminders for pending tasks.  
✅ **ContentUnavailableView** – Displays helpful messages when there are no tasks.

## 🎯 Why SwiftData?  

**SwiftData** makes data persistence seamless by providing an easy-to-use API for managing structured data. It eliminates the complexity of Core Data while maintaining performance and efficiency.  

## 🔊 Accessibility with VoiceOver  

VoiceOver enhances the app’s usability by allowing visually impaired users to navigate and interact with tasks using audio cues. Implementing accessibility ensures inclusivity and a better user experience for everyone.  

## ⏰ User Notifications  

The app sends reminders for tasks that haven't been completed, helping users stay organized and on top of their schedules.
